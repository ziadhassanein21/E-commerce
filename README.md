# L'Essence — Luxury Perfume E-Commerce

A modern, responsive e-commerce platform for luxury perfumes built with vanilla JavaScript (ES6) and Bootstrap.

## Features

- **Homepage** with hero section, featured products slider, and product collection
- **Product Catalog** with filtering by category (Men, Women, Unisex, Limited Edition)
- **Product Details** page with ratings and multiple volume options
- **Shopping Cart** with add/remove functionality
- **Wishlist** to save favorite products
- **User Authentication** with login and registration
- **User Profile** management
- **Checkout Process** with confirmation
- **Responsive Design** optimized for all devices
- **Modern UI** with smooth animations and scroll reveals

## Getting Started

1. Open `index.html` in a modern web browser
2. Browse the luxury perfume collection
3. Create an account or login
4. Add products to cart or wishlist
5. Proceed to checkout
